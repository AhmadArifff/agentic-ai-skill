# Local Knowledge & Production Case Bank

Direktori ini mencatat bug produksi lokal yang berhasil diselesaikan di proyek ini. Dengan mencatat kasus di sini:
1. Agen di sesi percakapan berikutnya tidak akan mengulangi kesalahan yang sama.
2. Kasus yang memiliki nilai umum dapat disinkronkan (*upstream*) ke Master Hub (`agentic AI`).

Format file kasus menggunakan YAML sesuai template [case-template.yaml](./case-template.yaml).
